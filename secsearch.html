Konfiguracja API & E2EE

Używany format: /api/search/{type}?uiv=4&t={type}&q={query}

Szyfruje ładunek tekstowy (payload) przed wysłaniem żądania do zaufanych węzłów, udowadniając koncepcję architektury Zero-Knowledge.

Brak ustawionego Custom API przełączy silnik w tryb agregacji z darmowych otwartych źródeł (SearXNG, DDG, Wiki). Zmiany są zapisywane wyłącznie w lokalnym localStorage.
